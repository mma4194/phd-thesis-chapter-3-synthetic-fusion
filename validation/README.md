# Validation records

`author_reference/SUMMARY.json` and `comparison.csv` record **228 passing comparisons** against the reported results. The experiment record comprises the completed Falcon generation run and the separately evaluated numeric-count CTGAN configurations. Machine paths are represented symbolically; expected values and numerical comparisons are preserved.

`software_checks.json` records the automated software checks for this repository edition. These cover implementation behaviour, source integrity and notebook structure. The notebook combines generation, the recorded CTGAN configurations and numerical comparison into one workflow.

Each reviewer execution produces its own final report, comparison tables and output inventory. The results guide explains these records and the procedure for comparing two independent runs.
